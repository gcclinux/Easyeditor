# EasyEditor Menu Structure & Feature Reference

This document outlines the complete menu hierarchy and feature entries available in **EasyEditor**.

---

## 🛠️ Main Navigation Bar (Top Bar)

### 📄 File
- **New File** (`Create a new document`)
- **Open Markdown** (`Open markdown .md file`)
- **Open TXT** (`Open plain text .txt file`)
- **Open Encrypted** (`Open encrypted .sstp file`)
- **Select Theme** (`Choose color scheme`)
- **Select Language** (`Choose interface language`)
- **License** (`Check license status & activation`)
- **APIConfig** (`EasyAI API Hosting & configuration`)
- **About** (`EasyEditor version and info`)
- **Support** (`Get help or sponsor the project`)
- **Website** (`Visit official website`)
- **Climate** (`Commitment to support climate action`)

### 📓 EasyNotes
- **Local & Cloud Document Library** (Sidebar panel for managing notes, folders, and markdown files)

### 🤖 EasyAI
- **AI Personas & Assistant** (AI documentation, diagram generation, code fixers, and repo scanner)

### 🌿 EasyGit
- **Git Operations Panel** (Init, Stage, Commit, Push, Pull, Branch Management, History, Credentials)

### 🔀 Split View
- **Toggle View Mode** (Switch between Edit Mode, Split View, and Full Live Preview)

### ↩️ Undo
- **Undo Edit** (Revert last text edit or action)

### ↪️ Redo
- **Redo Edit** (Reapply previously undone edit)

### 📤 Exports
- **Save** (`Save current file`)
- **Save As** (`Save As Markdown`)
- **Export Markdown** (`Save as Markdown .md file`)
- **Export to TXT** (`Save as plain text .txt file`)
- **Export to PNG** (`Export preview as Image`)
- **Export to PDF** (`Save document as PDF`)
- **Export Encrypted** (`Save as encrypted .sstp file`)
- **Google Drive** (`Save to Google Drive cloud storage`)
- **Dropbox** (`Save to Dropbox cloud storage`)
- **OneDrive** (`Save to OneDrive cloud storage`)
- **Box** (`Save to Box cloud storage`)
